# Hi, I’m the developer behind Prism AI

I’m building Prism AI, an early-stage workspace for research,
conversations, and writing.

## My main project

### Prism AI

Prism brings together tools for exploring questions and developing documents.

- Prism Chat: Conversations, research, projects, and Markdown documents.
- Prism Studio: AI-assisted LaTeX writing and document workflows.
- Browser demo: An interactive preview with fixed example content,
  separate from the Windows applications.

The browser demo does not connect to live AI.

[Explore the Prism AI repository](https://github.com/DudeSquad999/Prism-Ai)

## Current focus

- Making Prism clearer and easier to use.
- Improving the browser demo and documentation.
- Clearly separating working features, previews, and planned improvements.
